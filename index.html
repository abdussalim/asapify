ASAPify: rencana tim EWS karhutla gambut

ASAPify adalah WebGIS ringan untuk peringatan dini kebakaran lahan gambut. Sistem memetakan risiko setiap hari, mendeteksi titik api setiap jam, lalu agen Gemini menyusun peringatan yang rapi dan mudah dipahami. Peringatan baru terbit setelah disetujui operator.

Diputuskan minggu ini (paling lambat 30 Sep)

Sudah diputuskan: nama produk ASAPify. asap = smoke dalam bahasa Indonesia, ASAP = as soon as possible, dan -ify dari notify. Artinya: peringatan soal asap yang sampai secepatnya, dan sudah terverifikasi. Tagline: "In Indonesian, asap means smoke. We make sure responders hear about it ASAP, and know it's real."

  1. Anggota tim, 2 sampai 4 orang. Semuanya profesional bekerja dan berusia 21 tahun ke atas.
  2. Provinsi percontohan: Kalimantan Tengah (lokasi validasi jurnal ToPeCAl) atau Kalimantan Barat (area terbakar terluas 2026).
  3. Satu tanggal demo di Agustus atau September 2026 yang punya citra Landsat cerah di atas insiden nyata.

Lapisan 3 · verifikasi

ToPeCAl: empat ambang dari jurnal Sofan dkk. (2019), Tabel 3

Dihitung di Landsat-8/9 TOA. Kanal yang dipakai: B1 (aerosol, penanda asap), B6 (SWIR-1), B7 (SWIR-2), B10 (suhu kecerahan termal, Kelvin). SICI = B7 ÷ B6. Jurnal melaporkan akurasi 82%, naik jadi 93% setelah area perkotaan di-mask.

Sketsa ToPeCAl untuk Earth Engine (Python)topecal.py
import ee

def topecal(img):
    """0 = bukan api, 1 = membara (S), 2 = campuran (FS), 3 = menyala (F)."""
    b1, sw1, sw2, bt = (img.select(b) for b in ['B1', 'B6', 'B7', 'B10'])
    sici  = sw2.divide(sw1)
    asap  = b1.gte(0.27)
    cerah = asap.Not()

    s = sici.gt(1).And(bt.gte(297)).And(
            cerah.And(sw2.gte(0.09)).And(sw2.lte(0.31))
            .Or(asap.And(sw2.gte(0.11)).And(sw2.lte(0.32))))
    fs = sici.gt(1).And(
            cerah.And(sw2.gt(0.31)).And(bt.gt(300))
            .Or(asap.And(sw2.gte(0.32)).And(sw2.lte(0.47)).And(bt.gt(297))))
    f = (cerah.And(sw2.gte(0.68)).And(bt.gte(307))
            .Or(asap.And(sw2.gte(0.47)).And(bt.gte(303))))

    kelas = ee.Image(0).where(s, 1).where(fs, 2).where(f, 3)
    # mask area terbangun (sumber alarm palsu menurut jurnal)
    terbangun = ee.ImageCollection('ESA/WorldCover/v200').first().select('Map').eq(50)
    return kelas.updateMask(terbangun.Not()).rename('topecal')

def cari_landsat(titik, waktu):
    # waktu: ee.Date saat insiden terdeteksi
    koleksi = (ee.ImageCollection('LANDSAT/LC08/C02/T1_TOA')
               .merge(ee.ImageCollection('LANDSAT/LC09/C02/T1_TOA'))
               .filterBounds(titik)
               .filterDate(waktu.advance(-1, 'day'), waktu.advance(1, 'day'))
               .sort('system:time_start', False))
    return koleksi  # cek koleksi.size() dulu; 0 berarti "belum terverifikasi citra"

Jurnal memakai Landsat-8 Collection 1. Kita memakai Collection 2 TOA, jadi cek hasilnya secara visual pada 1–2 scene dulu sebelum dipercaya. Landsat melintas jarang, sehingga sebagian besar insiden akan berlabel "belum terverifikasi citra". Ini wajar dan perlu dijelaskan terus terang saat pitch.

Operator

Setujui, edit, atau tolak

Draf muncul di antrean panel operator. Setelah disetujui, statusnya menjadi approved dan kartu insiden tampil di peta publik.

Keputusan operator disimpan. Data ini dipakai untuk evaluasi dan tampil di deck.

Aturan untuk agen (masuk ke system prompt)

  • Level diambil dari aturan dan tidak boleh diubah.
  • Setiap angka harus berasal dari hasil tools. Kalau datanya kosong, tulis "tidak tersedia".
  • Bahasa sederhana, kalimat pendek, maksimal 60 kata per pesan.
  • Tidak menyebut api "pasti" kalau belum ada verifikasi citra.

Validator setelah Gemini menjawab (kode Python biasa)

  • JSON sesuai skema (structured output).
  • Level di JSON sama dengan level dari aturan.
  • Setiap angka di teks cocok dengan data tools.
  • Kalau gagal, ulangi sekali. Kalau masih gagal, tandai draf "perlu dicek".

Jalankan pada 20–30 insiden historis dan catat persentase yang lolos. Angka ini menjadi bukti kualitas GenAI di deck.

13 · Istilah

Kamus singkat untuk tim

Hotspot (titik panas)
Piksel satelit yang jauh lebih panas dari sekitarnya. Belum tentu kebakaran.
NASA FIRMS
Layanan gratis yang mengirim data hotspot dari satelit VIIRS dan MODIS, beberapa jam setelah satelit lewat.
VIIRS
Sensor di tiga satelit (S-NPP, NOAA-20, NOAA-21). Resolusi 375 m, lewat beberapa kali sehari.
FRP
Fire Radiative Power, perkiraan besarnya energi api dalam megawatt.
KHG
Kesatuan Hidrologis Gambut, satuan wilayah gambut yang dipakai pemerintah.
Insiden
Kumpulan hotspot yang berdekatan (1 km) dalam 24 jam, dianggap satu kejadian.
Landsat TOA
Citra Landsat yang nilainya sudah dikonversi ke reflektansi di puncak atmosfer. Dipakai langsung oleh ToPeCAl.
SWIR dan termal
Kanal inframerah gelombang pendek (peka terhadap api) dan kanal suhu permukaan.
ToPeCAl
Tropical Peatland Combustion Algorithm dari Sofan dkk. (2019). Empat ambang untuk mengenali api menyala dan membara.
Membara vs menyala
Membara (smouldering) adalah api bersuhu rendah di bawah permukaan gambut. Lebih sulit dilihat satelit.
ADK
Agent Development Kit dari Google, kerangka untuk membangun agen Gemini yang bisa memanggil fungsi (tools).
Structured output
Gemini dipaksa menjawab dalam JSON sesuai skema, sehingga mudah diperiksa oleh kode.
Human-in-the-loop
Keputusan akhir tetap di tangan manusia. Di sistem ini perannya dipegang operator.
Sitrep
Situation report, ringkasan kondisi harian untuk satgas.
Mode replay
Menjalankan sistem seolah-olah pada tanggal lampau, untuk demo dan pengujian.
Cloud Run job vs service
Job berjalan sampai selesai lalu berhenti (cocok untuk tugas tiap jam). Service selalu siap menerima permintaan.
