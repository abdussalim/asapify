05b · Wilayah Kalimantan ✅

Satu grid, lima provinsi, hanya piksel gambut

Wilayah dikunci ke gambut Kalimantan (✅ 29 Sep). Semua job, backtest, dan UI memakai konstanta yang sama dari jobs/lib/region.py. Kode di bawah 💡 titik awal; bagian bertanda ⚠️ dicek saat Sprint 0.

# lon_min, lat_min, lon_max, lat_max (WGS84)
MONITOR_BBOX  = (108.5, -4.4, 119.4, 4.5)   # seluruh Kalimantan
BACKTEST_BBOX = (113.5, -2.6, 114.3, -1.9)  # contoh sub-area Kalteng

    return f"p{row}_{col}"                  # baris 0 = utara

Kenapa bbox saja tidak cukup

  • Kotak MONITOR_BBOX ikut mencakup Sarawak, Sabah, Brunei, dan sebagian pantai Sulawesi Barat.
  • KHG hanya berisi Indonesia, jadi Malaysia dan Brunei otomatis keluar. Pantai Sulawesi dikeluarkan dengan filter provinsi (kode 61–65).
  • Kolom province per piksel juga dipakai untuk memilih grup Telegram peringatan.

Peat mask: KHG + provinsi + terbangunjobs/build_peat_mask.py
import geopandas as gpd, numpy as np, requests
from rasterio import features, transform
from jobs.lib.region import MONITOR_BBOX, GRID_DEG, AREA, PROVINCES, pixel_id

KHG = ("https://kspservices.big.go.id/satupeta/rest/services/PUBLIK/"
       "SUMBER_DAYA_ALAM_DAN_LINGKUNGAN/MapServer/37/query")

def fetch_khg(bbox):
    feats, off = [], 0
    while True:                                 # maks 1.000 fitur/request
        r = requests.get(KHG, timeout=120, params={
            "where": "1=1", "outFields": "kode_khg", "f": "geojson",
            "geometry": ",".join(map(str, bbox)),
            "geometryType": "esriGeometryEnvelope", "inSR": 4326,
            "outSR": 4326, "resultOffset": off, "resultRecordCount": 1000})
        page = r.json()["features"]; feats += page
        if len(page) < 1000: return gpd.GeoDataFrame.from_features(feats, crs=4326)
        off += 1000

def fraction(gdf, sub=10):                      # fraksi luas per sel 0,02°
    h, w = AREA.shape
    t = transform.from_bounds(*MONITOR_BBOX, w * sub, h * sub)
    fine = features.rasterize(gdf.geometry, (h * sub, w * sub), transform=t)
    return fine.reshape(h, sub, w, sub).mean(axis=(1, 3))

khg  = fetch_khg(MONITOR_BBOX).make_valid()
prov = gpd.read_file("data/ref/kalimantan_prov.geojson")   # dari Runbook S0-8, kolom code
peat_frac  = fraction(khg.clip(prov))                 # hanya 5 provinsi
built_frac = np.load("data/ref/built_frac_002.npy")   # dari WorldCover/PKTL, grid sama

keep = (peat_frac >= 0.5) & (built_frac < 0.2)
rows, cols = np.nonzero(keep)
lon, lat = AREA.get_lonlats()
df = gpd.GeoDataFrame({
    "pixel_id": [pixel_id(r, c) for r, c in zip(rows, cols)],
    "lat": lat[rows, cols], "lon": lon[rows, cols],
    "peat_frac": peat_frac[rows, cols], "built_frac": built_frac[rows, cols],
}, geometry=gpd.points_from_xy(lon[rows, cols], lat[rows, cols]), crs=4326)
df = (df.sjoin(prov[["code", "geometry"]]).drop(columns="index_right")
        .rename(columns={"code": "province"}))
df = df.sjoin(khg[["kode_khg", "geometry"]], how="left")
df.drop(columns=["geometry", "index_right"]).to_parquet(
    f"gs://{DATA_BUCKET}/peat/pixels.parquet")

from satpy import Scene
from jobs.lib.region import AREA

def read_scan(files):                        # hasil list_scan(ts)
    scn = Scene(reader="ahi_hsd", filenames=files)   # .DAT.bz2 ⚠️ cek dukungan
    scn.load(["B07", "B14"], calibration="brightness_temperature")
    local = scn.resample(AREA, resampler="nearest",
                         radius_of_influence=5000)
    b07, b14 = local["B07"].values, local["B14"].values   # 445 × 545, kelvin
    return b07, b14, b07 - b14

# backtest    : VIIRS_SNPP_SP, VIIRS_NOAA20_SP (arsip), potongan 5 hari (day_range maks 5)

def to_pixels(df, peat):
    df = df[df.daynight == "N"].copy()
    df["row"] = ((MONITOR_BBOX[3] - df.latitude) // GRID_DEG).astype(int)
    df["col"] = ((df.longitude - MONITOR_BBOX[0]) // GRID_DEG).astype(int)
    df["pixel_id"] = "p" + df.row.astype(str) + "_" + df.col.astype(str)
    df["strong"] = df.confidence.isin(["n", "h"])
    return df[df.pixel_id.isin(peat.pixel_id)]

Kirim dan edit pesanapi/telegram.py
TG = f"https://api.telegram.org/bot{TOKEN}"

async def send_alert(alert, chat_id, photo_url):
    r = await http.post(f"{TG}/sendPhoto", json={
        "chat_id": chat_id,
        "photo": photo_url,          # signed URL crop Himawari
        "caption": alert.caption_id, # ≤ 1024 karakter
        "parse_mode": "HTML"})
    msg = r.json()["result"]
    return {"chat_id": chat_id, "message_id": msg["message_id"]}

async def update_alert(alert):         # level naik / ditutup
    await http.post(f"{TG}/editMessageCaption", json={
        "chat_id": alert.telegram.chat_id,
        "message_id": alert.telegram.message_id,
        "caption": alert.caption_id,
        "parse_mode": "HTML"})

07 · Job

Langkah di setiap job

asapify-ingest · tiap 10 menit
  1. Cari scan full disk terbaru di noaa-himawari9; lewati bila sudah diproses (idempoten per timestamp).
  2. Baca hanya segmen yang mencakup Kalimantan; kalibrasi band 7 dan 14 (satpy ahi_hsd). Band visible diambil sesuai permintaan oleh tool agen.
  3. Resample ke grid 0,02°, ambil piksel gambut dari peat mask.
  4. Tandai awan (b14 < 270 K) → skor NaN.
  5. Hitung skor z terhadap baseline dan z_rel terhadap tetangga; tulis bt/ dan score/.
  6. Pada scan malam: perbarui nights/ (n_valid, z_night, deteksi VIIRS dari firms/), evaluasi status dengan aturan gabungan (Rencana 05), kelompokkan piksel anomaly jadi cluster.
  7. Status berubah (transisi) dan cooldown habis → POST /internal/agent/analyze. Setelah analisis tersimpan, API mengirim ringkasan ke grup Telegram operator.
  8. Catat latensi (waktu scan vs waktu file tersedia) di runs.
asapify-firms · menit 5 dan 35 tiap jam
  1. Tarik VIIRS_SNPP_NRT, VIIRS_NOAA20_NRT, VIIRS_NOAA21_NRT untuk MONITOR_BBOX, day_range = 1.
  2. Buang deteksi siang (daynight = "D") dan titik di luar sel piksel gambut.
  3. Tambahkan ke firms/YYYY/MM/DD.parquet, buang duplikat pada kunci satellite, acq_date, acq_time, latitude, longitude.
  4. Catat jumlah baris baru di runs. Rule engine membaca file ini di ingest berikutnya.
asapify-baseline · harian 12.00 WIB
  1. Ambil 30 hari bt/ terakhir per piksel per jam.
  2. Hitung median dan MAD, abaikan no_observation.
  3. Piksel yang sedang ter-flag: pertahankan baseline lama (frozen = true).
  4. Tulis baseline/MM/HH.parquet.
Peat mask dibangun sekali lewat build_built_frac.py lalu build_peat_mask.py (bagian 05b): poligon KHG dari REST BIG (layer 37) → fraksi gambut per piksel; tutupan lahan (PKTL atau WorldCover) → fraksi terbangun per piksel. Baseline awal untuk jendela backtest dihitung dari arsip Himawari sebelum jendela itu.
