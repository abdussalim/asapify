Five deterministic jobs, two services

Observation (Himawari-9, GK2A), baselines (NASA POWER + thermal baseline) and the rule engine (MAUT + neighbour support) run as Cloud Run jobs. The ADK agent lives in the asapify-agent service and is called only for AWAS clusters; it fetches VIIRS at that moment (on demand). The asapify-api service serves operators and subscribers; once an operator publishes, the message reaches the inbox and Telegram DMs of that province's subscribers through the asapify-notify worker. Code on this page is a 💡 starting point; ⚠️ parts are checked in Sprint 0.

02 · Conventions

Apply to every job and endpoint

Base path
Operator API: /api/v1, through Firebase Hosting (same origin as the web app). Agent: /verify on the private Cloud Run URL.
Format
UTF-8 JSON, coordinates [lon, lat]. The web map uses a compact format: a static pixel index once (/operator/pixels), then one status letter per cell (S, N, W, A). For 10k cells that is ≈ 23 KB raw / 11 KB gzip, against ≈ 1.9 MB / 83 KB for GeoJSON. GeoJSON points stay available (format=geojson, the default) for other tools.
Time
ISO 8601. Store UTC, display WIB. slot = the 10-minute scan time in UTC.
IDs
pixel p{row}_{col} on the 0.02° Sumatra + Kalimantan grid (1,225 × 620, origin 94.9° E / 6.2° N, row 0 in the north); cluster C-{MMDD}-{nnn}; verification {cluster_id}_{slot:%Y%m%dT%H%M}
Status
SAFE, NO_OBSERVATION, WATCH, AWAS (upper case, exactly)
Operator auth
Firebase ID token, claim role = "operator"
Internal auth
OIDC from sa-jobs or sa-api to asapify-agent (Cloud Run IAM run.invoker)
Replay
jobs: --as-of or env AS_OF; endpoints: as_of; response header X-Asapify-As-Of
Errors
{"error": {"code": "...", "message": "..."}}. code is stable; the web app writes its own message from code in the operator's language (EN/ID). message (Indonesian) shows only when the web app does not know the code yet.
Language
Agent text is sent in both languages (finding + finding_en, summary_id + summary_en) so a screen never mixes languages. Alert message text (inbox and Telegram DM) stays in Indonesian.

Why the bbox alone is not enough

  • The MONITOR_BBOX box also covers Peninsular Malaysia, Singapore, Sarawak, Sabah, Brunei, the western tip of Java and part of the West Sulawesi coast.
  • KHG covers Indonesia only, so Malaysia, Singapore and Brunei drop out automatically. Java and Sulawesi are removed with the province filter (codes 11–19, 21, 61–65).
  • The per-pixel province column also decides which subscribers receive the alert (subscribers choose provinces).

Peat mask: KHG + provinces + built-upjobs/build_peat_mask.py
import geopandas as gpd, numpy as np, requests
from rasterio import features, transform
from jobs.lib.region import MONITOR_BBOX, GRID_DEG, AREA, pixel_id

KHG = ("https://kspservices.big.go.id/satupeta/rest/services/PUBLIK/"
       "SUMBER_DAYA_ALAM_DAN_LINGKUNGAN/MapServer/37/query")

def fetch_khg(bbox):
    feats, off = [], 0
    while True:                                 # max 1,000 features/request
        r = requests.get(KHG, timeout=120, params={
            "where": "1=1", "outFields": "kode_khg", "f": "geojson",
            "geometry": ",".join(map(str, bbox)),
            "geometryType": "esriGeometryEnvelope", "inSR": 4326,
            "outSR": 4326, "resultOffset": off, "resultRecordCount": 1000})
        page = r.json()["features"]; feats += page
        if len(page) < 1000: return gpd.GeoDataFrame.from_features(feats, crs=4326)
        off += 1000

def fraction(gdf, sub=10):                      # area fraction per 0.02° cell
    h, w = AREA.shape
    t = transform.from_bounds(*MONITOR_BBOX, w * sub, h * sub)
    fine = features.rasterize(gdf.geometry, (h * sub, w * sub), transform=t)
    return fine.reshape(h, sub, w, sub).mean(axis=(1, 3))

khg  = fetch_khg(MONITOR_BBOX).make_valid()
prov = gpd.read_file("data/ref/provinces.geojson")   # 15 provinces, Runbook S0-8
peat_frac  = fraction(khg.clip(prov))
built_frac = np.load("data/ref/built_frac_002.npy")

keep = (peat_frac >= 0.5) & (built_frac < 0.2)
rows, cols = np.nonzero(keep)
lon, lat = AREA.get_lonlats()
df = gpd.GeoDataFrame({
    "pixel_id": [pixel_id(r, c) for r, c in zip(rows, cols)],
    "row": rows, "col": cols,
    "lat": lat[rows, cols], "lon": lon[rows, cols],
    "peat_frac": peat_frac[rows, cols], "built_frac": built_frac[rows, cols],
}, geometry=gpd.points_from_xy(lon[rows, cols], lat[rows, cols]), crs=4326)
df = (df.sjoin(prov[["code", "geometry"]]).drop(columns="index_right")
        .rename(columns={"code": "province"}))
df = df.sjoin(khg[["kode_khg", "geometry"]], how="left")
df.drop(columns=["geometry", "index_right"]).to_parquet(
    f"gs://{DATA_BUCKET}/peat/pixels.parquet")

Neighbours + POWER cells (once)jobs/build_neighbors.py, build_power_cells.py
peat = pd.read_parquet(f"gs://{DATA_BUCKET}/peat/pixels.parquet")
idx = {(r, c): p for p, r, c in zip(peat.pixel_id, peat.row, peat.col)}

def around(r, c, k):        # k=1 → 8 directions; k=5 → 5-cell radius
    return [idx[(r+i, c+j)] for i in range(-k, k+1) for j in range(-k, k+1)
            if (i or j) and (r+i, c+j) in idx and (k == 1 or i*i + j*j <= k*k)]

for k, name in ((1, "neighbors8"), (5, "neighbors_r5")):
    pd.DataFrame({"pixel_id": peat.pixel_id,
                  "neighbor_ids": [around(r, c, k) for r, c in zip(peat.row, peat.col)]}
                 ).to_parquet(f"gs://{DATA_BUCKET}/peat/{name}.parquet")

# NASA POWER cell (GEOS-IT 0.5° × 0.625°)
peat["cell_lat"] = (peat.lat / 0.5).round() * 0.5
peat["cell_lon"] = (peat.lon / 0.625).round() * 0.625
peat["cell_id"] = [f"c{a:+.1f}_{o:.3f}" for a, o in zip(peat.cell_lat, peat.cell_lon)]
cells = (peat.groupby("cell_id")
             .agg(lat=("cell_lat", "first"), lon=("cell_lon", "first"),
                  n_pixels=("pixel_id", "size")).reset_index())
05c · Observation: Himawari-9 and GK2A

Two readers, one output format

Both ingests write the same columns (pixel_id, mir, win, cloud), so the rule engine never needs to know which satellite it reads. Only night slots (13:00–20:50 UTC) are processed.

Himawari-9 (segments)jobs/lib/himawari.py
import os, s3fs
from satpy import Scene
from jobs.lib.region import AREA

fs = s3fs.S3FileSystem(anon=True)
SEGMENTS = ("S0510", "S0610")              # ⚠️ checked in S0-7

def list_scan(slot):                       # slot: UTC datetime, multiple of 10 minutes
    d = f"noaa-himawari9/AHI-L1b-FLDK/{slot:%Y/%m/%d/%H%M}"
    return [f for f in fs.ls(d)
            if any(f"_{b}_" in f for b in ("B07", "B14"))
            and any(s in f for s in SEGMENTS)]      # 4 files

def read_scan(files, tmp):
    local = []
    for f in files:
        p = os.path.join(tmp, os.path.basename(f)); fs.get(f, p); local.append(p)
    scn = Scene(reader="ahi_hsd", filenames=local)  # .DAT.bz2 ⚠️
    scn.load(["B07", "B14"], calibration="brightness_temperature")
    g = scn.resample(AREA, resampler="nearest", radius_of_influence=5000)
    return g["B07"].values, g["B14"].values        # mir, win (445 × 545, K)
GK2A (full disk)jobs/lib/gk2a.py
import os, s3fs
from satpy import Scene
from jobs.lib.region import AREA

fs = s3fs.S3FileSystem(anon=True)
CHANNELS = ("sw038", "ir105")

def list_scan(slot):                       # archive starts 16 Feb 2023
    d = f"noaa-gk2a-pds/AMI/L1B/FD/{slot:%Y%m/%d/%H}"
    return [f"{d}/gk2a_ami_le1b_{ch}_fd020ge_{slot:%Y%m%d%H%M}.nc"
            for ch in CHANNELS]            # 2 files × ~30 MB

def read_scan(files, tmp):
    local = []
    for f in files:
        p = os.path.join(tmp, os.path.basename(f)); fs.get(f, p); local.append(p)
    scn = Scene(reader="ami_l1b", filenames=local)
    scn.load(["SW038", "IR105"], calibration="brightness_temperature")
    g = scn.resample(AREA, resampler="nearest", radius_of_influence=5000)
    for p in local: os.remove(p)           # do not keep the full disk
    return g["SW038"].values, g["IR105"].values

CLOUD_K = 270.0                              # window channel < 270 K = cloud

def to_features(mir, win, peat):
    r, c = peat.row.values, peat.col.values
    df = pd.DataFrame({"pixel_id": peat.pixel_id.values,
                       "mir": mir[r, c], "win": win[r, c]})
    df["cloud"] = (df.win < CLOUD_K) | df.win.isna()
    return df                                # → {sat}/YYYY/MM/DD/HHMM.parquet
05d · Baselines: NASA POWER and the thermal baseline

What "normal" looks like for each night hour

NASA POWER hourly data arrive ~1.5 days late and are coarse (0.5° × 0.625°), so they serve as a 30-day median per hour, not as tonight's value. There is no area endpoint for hourly data: one request per cell.

NASA POWERjobs/lib/power.py
URL = "https://power.larc.nasa.gov/api/temporal/hourly/point"

def fetch_cell(lat, lon, start, end):
    r = httpx.get(URL, timeout=120, params={
        "parameters": "TS,T2M", "community": "RE",
        "latitude": lat, "longitude": lon,
        "start": f"{start:%Y%m%d}", "end": f"{end:%Y%m%d}",
        "format": "JSON", "time-standard": "UTC"})
    p = r.json()["properties"]["parameter"]
    df = pd.DataFrame({"ts": p["TS"], "t2m": p["T2M"]}).replace(-999.0, np.nan)
    df.index = pd.to_datetime(df.index, format="%Y%m%d%H", utc=True)
    return df + 273.15                       # °C → K

def power_baseline(raw, as_of, days=30):     # raw: cell_id, time, ts, t2m
    w = raw[(raw.time > as_of - pd.Timedelta(days=days)) & (raw.time <= as_of)]
    w = w[w.time.dt.hour.isin(range(13, 21))]
    g = w.assign(hour_utc=w.time.dt.hour).groupby(["cell_id", "hour_utc"])
    return pd.DataFrame({"ts_base": g.ts.median(), "t2m_base": g.t2m.median(),
                         "n_days": g.ts.count()}).reset_index()
Thermal baseline and LST biasjobs/lib/baseline.py
def thermal_baseline(feats, as_of, nights=30, frozen_ids=(), prev=None):
    # feats: pixel_id, slot, mir, cloud from one satellite, 30 nights ≤ as_of
    f = feats[~feats.cloud].assign(hour_utc=feats.slot.dt.hour)
    g = f.groupby(["pixel_id", "hour_utc"]).mir
    base = pd.DataFrame({"median": g.median(),
                         "mad": g.apply(lambda x: (x - x.median()).abs().median()),
                         "n_obs": g.size()}).reset_index()
    base["frozen"] = base.pixel_id.isin(frozen_ids)
    if prev is not None:                     # WATCH/AWAS pixels keep the old rows
        base = pd.concat([base[~base.frozen],
                          prev[prev.pixel_id.isin(frozen_ids)].assign(frozen=True)])
    return base

def lst_bias(win_max, power, cells):
    # b_LST = 30-night median of (win_max − ts_base) per pixel per hour
    d = (win_max.merge(cells, on="pixel_id")
                .merge(power, on=["cell_id", "hour_utc"]))
    d["x"] = d.win_max - d.ts_base
    return d.groupby(["pixel_id", "hour_utc"]).x.median().rename("b_lst")
05e · Rule engine: MAUT + neighbour support

Pure functions, one dict for every number

The numbers are exactly Plan 05. Change only W, RAMP and T, then record it in WORKLOG section 7.

Utilityjobs/lib/maut.py
import numpy as np

W    = {"H": .25, "G": .25, "LST": .10, "SAT": .05, "T": .15, "N": .20}
RAMP = {"H": (2.0, 4.0), "G": (2.0, 4.0), "LST": (1.0, 4.0), "SAT": (0.0, 3.0)}

def ramp(x, a, b):
    return np.clip((x - a) / (b - a), 0.0, 1.0)   # NaN stays NaN

def attributes(zrel_h, zrel_g, d_lst, d_sat, k_nights):
    return {"H": ramp(zrel_h, *RAMP["H"]), "G": ramp(zrel_g, *RAMP["G"]),
            "LST": ramp(d_lst, *RAMP["LST"]), "SAT": ramp(d_sat, *RAMP["SAT"]),
            "T": np.minimum(k_nights / 3.0, 1.0)}

def weighted(u, keys):                    # weights normalised over available attributes
    num = sum(np.where(np.isnan(u[k]), 0, u[k]) * W[k] for k in keys)
    den = sum(np.where(np.isnan(u[k]), 0, W[k]) for k in keys)
    return np.where(den > 0, num / np.where(den > 0, den, 1), np.nan)

def u0(u):
    return weighted(u, ["H", "G", "LST", "SAT", "T"])

def utility(u, u_n):
    return weighted({**u, "N": u_n}, ["H", "G", "LST", "SAT", "T", "N"])
Neighboursjobs/lib/neighbours.py
def support(u0: pd.Series, nbr8: pd.DataFrame) -> pd.Series:
    # u0: index pixel_id; nbr8: pixel_id, neighbor_ids[]
    def one(ids):
        v = u0.reindex(ids).dropna()          # observed neighbours only
        return float((v >= 0.5).mean()) if len(v) else 0.0
    return pd.Series(nbr8.neighbor_ids.map(one).values, index=nbr8.pixel_id)
Statusjobs/lib/status.py
T = {"awas_u": 0.65, "awas_n": 0.25, "watch_u": 0.30}

def classify(U, u_n, agree, n_sat):
    return np.select(
        [n_sat == 0,
         (U >= T["awas_u"]) & (u_n >= T["awas_n"]) & agree,
         U >= T["watch_u"]],
        ["NO_OBSERVATION", "AWAS", "WATCH"], default="SAFE")
# agree = u_H ≥ 0.5 and u_G ≥ 0.5, each in ≥ 1 slot within 60 minutes
Order inside jobs/evaluate.py: read slot features → anomaly.zscore per satellite → ΔLST, ΔSAT → maut.attributes → u0 → neighbours.support → utility → status.classify → write score/ → cluster.label → POST /verify for new clusters.

FIRMS = "https://firms.modaps.eosdis.nasa.gov/api/area/csv/{k}/{src}/{w},{s},{e},{n}/{days}"
SATS = ("VIIRS_SNPP", "VIIRS_NOAA20", "VIIRS_NOAA21")

def get_latest_viirs(lat: float, lon: float, as_of: str,
                     radius_km: float = 10, hours: int = 48) -> dict:
    t = parse_utc(as_of); d = radius_km / 111
    recent = (now_utc() - t).days <= 7          # NRT; otherwise the SP archive
    rows = []
    for sat in SATS:
        src = f"{sat}_NRT" if recent else f"{sat}_SP"
        url = FIRMS.format(k=MAP_KEY, src=src, w=lon-d, s=lat-d, e=lon+d, n=lat+d, days=2)
        if not recent:
            url += f"/{t - timedelta(days=1):%Y-%m-%d}"   # ⚠️ meaning of the date: S0-6
        try: rows.append(read_csv(cached_get(url)).assign(src=src))
        except SourceUnavailable: continue       # e.g. NOAA21 SP not available yet
    df = pd.concat(rows)
    df["time_utc"] = to_utc(df.acq_date, df.acq_time)
    df = df[(df.time_utc > t - timedelta(hours=hours)) & (df.time_utc <= t)]
    df["distance_km"] = haversine(lat, lon, df.latitude, df.longitude)
    df = df[df.distance_km <= radius_km].sort_values("distance_km")
    return {"detections": df[["src", "time_utc", "daynight", "confidence",
                              "frp", "distance_km"]].to_dict("records"),
            "within_2km": int((df.distance_km <= 2).sum())}

GIBS = "https://gibs.earthdata.nasa.gov/wms/epsg4326/best/wms.cgi"
LAYERS = [f"{s}_CorrectedReflectance_TrueColor"
          for s in ("VIIRS_NOAA21", "VIIRS_NOAA20", "VIIRS_SNPP")]

def fetch_viirs_image(lat: float, lon: float, as_of: str,
                      half_deg: float = 0.2) -> dict:
    t = parse_utc(as_of)
    for back in range(0, 4):                     # WIB date of as_of, back ≤ 3 days
        day = (t + timedelta(hours=7)).date() - timedelta(days=back)
        for layer in LAYERS:
            r = httpx.get(GIBS, timeout=60, params={
                "SERVICE": "WMS", "REQUEST": "GetMap", "VERSION": "1.3.0",
                "LAYERS": layer, "CRS": "EPSG:4326",
                "BBOX": f"{lat-half_deg},{lon-half_deg},{lat+half_deg},{lon+half_deg}",
                "WIDTH": 512, "HEIGHT": 512, "FORMAT": "image/jpeg",
                "TIME": f"{day:%Y-%m-%d}"})
            img = Image.open(io.BytesIO(r.content))
            if np.asarray(img).std() < 3: continue    # blank / no data
            png = draw_marker(img, radius_km=5)       # dot + 5 km circle
            path = save_crop(png, pixel_id, t, "viirs")
            return {"path": path, "signed_url": sign(path, hours=1),
                    "layer": layer, "date": str(day),
                    "age_h": hours_since(day, local_time="13:30", tz="+07:00", now=t)}
    return {"none": True, "reason": "no image in the last 3 days"}

07 · Jobs

Steps inside each job

asapify-ingest-himawari / -gk2a · */10 at night
  1. Pick the slot: AS_OF rounded down to a multiple of 10 minutes; process that slot + any missing night slot from the last 60 minutes. Outside 13:00–20:50 UTC: exit without action.
  2. list_scan(slot); if files are incomplete, record it in runs (pending) and exit. The next cycle retries.
  3. read_scan → 0.02° grid → to_features (peat pixels only).
  4. Write {sat}/YYYY/MM/DD/HHMM.parquet (idempotent: overwrite) and the source file manifest in raw/{sat}/manifest/.
  5. Record latency (slot time vs the file's LastModified) in runs.
asapify-evaluate · minutes 5, 15, … at night
  1. Pick the latest slot where both satellites are present; if one satellite is > 40 minutes late, run with one satellite (n_sat = 1). Skip slots already in runs.
  2. Read the latest thermal baseline, LST bias and POWER from environment/.
  3. Compute z, ΔLST, ΔSAT, attributes, U0, u_N, U, status (05e). Write score/.
  4. Label AWAS clusters (cluster.label), update clusters, close clusters without AWAS for 3 valid nights, then POST $AGENT_URL/cluster-closed so any published alert is marked SELESAI.
  5. For new clusters, or when the last verification is > 6 h old: POST $AGENT_URL/verify with an OIDC token.
asapify-environment · daily 12:00 WIB
  1. For each cell in peat/power_cells.parquet: request the days missing from raw/power/{cell_id}.parquet (0.2 s pause between requests).
  2. power_baseline → environment/power/YYYYMMDD.parquet.
  3. thermal_baseline per satellite from 30 nights of himawari/ and gk2a/; WATCH/AWAS pixels are frozen.
  4. lst_bias → environment/bias/YYYYMMDD.parquet.
asapify-build · once
  1. build_built_frac (Earth Engine WorldCover).
  2. build_peat_mask (BIG KHG + provinces + built_frac).
  3. build_neighbors (8 directions, radius 5) and build_power_cells.

The backtest backfill uses the same image and ingest code: python -m jobs.backfill --sat … --start … --end … --step 10|20 --night-only, run as an 8-task Cloud Run job.

09 · Errors

What happens when something fails

EventBehaviour
One satellite's scan is not available yetIngest exits without action; evaluate waits up to 40 minutes, then runs with one satellite (n_sat = 1, AWAS impossible).
Both satellites missing or corruptEvery pixel is NO_OBSERVATION for that slot; recorded in runs.
NASA POWER fails / is lateEnvironment uses the latest available POWER baseline (max 3 days); older than that → u_LST and u_SAT are dropped (NaN) and the weights are normalised.
FIRMS or GIBS failsThe tool returns an error; the agent continues with the evidence it has and the result is inconclusive, noting the failed source.
Gemini fails or the tool limit is reachedThe verification is saved as inconclusive with validator_failed / tool_limit; the operator can request re-verification.
Two operators decide at the same timeFirestore transaction; the second gets 409 ALREADY_DECIDED and the web app shows the decision already saved.
Archive night without data/operator/nights sends has_data = false (a faded date in the calendar); /operator/grid/night sends every slot as null and the web app shows every pixel as unobserved with a banner.
A send fails or is uncertain (429, network, worker died)The decision and inbox stay saved. 4xx = failed; a timeout or a worker dying after the claim = unknown, never resent automatically. The operator sees per-channel status at /deliveries.
