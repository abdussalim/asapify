06 · Himawari (NOAA open data)

Akses anonim, unduh segmen yang perlu saja

Bucket publik noaa-himawari9 (us-east-1), full disk tiap 10 menit, arsip sejak Juli 2015. Dibaca anonim, tanpa akun AWS dan tanpa biaya; ini hanya arsip unduhan, bukan infrastruktur kita. Di materi submit sebut "NOAA open data". ⚠️ Cek struktur folder dan nama file di S3 Explorer sebelum menulis parser.

Daftar file satu scanjobs/lib/himawari.py
import s3fs
fs = s3fs.S3FileSystem(anon=True)

def list_scan(ts):  # ts: datetime UTC, kelipatan 10 menit
    prefix = f"noaa-himawari9/AHI-L1b-FLDK/{ts:%Y/%m/%d/%H%M}/"
    files = fs.ls(prefix)
    # ingest rutin: band 07 dan 14 saja (visible diambil sesuai permintaan)
    # Kalimantan ±4,5° dari ekuator: kemungkinan segmen S05 dan S06 ⚠️ cek
    return [f for f in files
            if any(b in f for b in ("B07", "B14"))
            and any(sg in f for sg in ("S0510", "S0610"))]

09 · Cloud Run service

asapify-api

Deploybash
gcloud run deploy asapify-api --source . --region $REGION \
  --command uvicorn --args=api.main:app,--host,0.0.0.0,--port,8080 \
  --service-account $API_SA --allow-unauthenticated \
  --cpu 1 --memory 2Gi --concurrency 20 \
  --min-instances 0 --max-instances 3 --timeout 180 \
  --set-env-vars "GOOGLE_CLOUD_PROJECT=$PROJECT_ID,GOOGLE_CLOUD_LOCATION=$GEMINI_LOCATION,\

gcloud run services add-iam-policy-binding asapify-api --region $REGION \
  --member "serviceAccount:$JOBS_SA" --role roles/run.invoker

Menyiapkan grup

  2. Buat dua grup: ASAPify Operator dan ASAPify Peringatan (demo). Tambahkan bot ke keduanya.
  3. Kirim pesan apa saja di tiap grup, lalu ambil chat_id lewat getUpdates (lihat Backend 06b). Simpan ke koleksi tg_chats.
  4. Untuk penjurian: undang akun juri ke grup peringatan demo, atau tampilkan grup di video.
10 · Job dan Scheduler

Empat job: ingest 10 menit, FIRMS 30 menit, baseline harian, build sekali

Deploy job dan jadwalbash
API_URL=$(gcloud run services describe asapify-api --region $REGION --format='value(status.url)')
ENV="GOOGLE_CLOUD_PROJECT=$PROJECT_ID,DATA_BUCKET=$DATA_BUCKET,BBOX=$BBOX,API_URL=$API_URL"
COMMON="--source . --region $REGION --service-account $JOBS_SA --command python --set-env-vars $ENV"

gcloud run jobs deploy asapify-ingest   $COMMON --args=-m,jobs.ingest \
  --cpu 2 --memory 4Gi --task-timeout 8m  --max-retries 0
gcloud run jobs deploy asapify-firms    $COMMON --args=-m,jobs.firms_pull,--day-range,1 \
  --cpu 1 --memory 1Gi --task-timeout 5m  --max-retries 1 \
  --set-secrets FIRMS_MAP_KEY=firms-map-key:latest
gcloud run jobs deploy asapify-baseline $COMMON --args=-m,jobs.baseline \
  --cpu 2 --memory 4Gi --task-timeout 30m --max-retries 1
gcloud run jobs deploy asapify-build    $COMMON --args=-m,jobs.build_all \
  --cpu 2 --memory 8Gi --task-timeout 60m --max-retries 0     # sekali: built_frac → peat mask → neighbors

for JOB in asapify-ingest:"*/10 * * * *" asapify-firms:"5,35 * * * *" asapify-baseline:"0 12 * * *"; do
  NAME="${JOB%%:*}"; CRON="${JOB#*:}"
  gcloud scheduler jobs create http "$NAME-schedule" --location $REGION \
    --schedule "$CRON" --time-zone "Asia/Jakarta" \
    --uri "https://run.googleapis.com/v2/projects/$PROJECT_ID/locations/$REGION/jobs/$NAME:run" \
    --http-method POST --oauth-service-account-email $SCHED_SA
done

# sekali setelah deploy
gcloud run jobs execute asapify-build --region $REGION --wait

# replay satu scan (argumen menggantikan --args bawaan job)
gcloud run jobs execute asapify-ingest --region $REGION --wait \
  --args=-m,jobs.ingest,--as-of,2019-09-15T15:00:00Z

# backfill paralel: 8 task, tiap task mengambil tanggal dengan CLOUD_RUN_TASK_INDEX
gcloud run jobs execute asapify-ingest --region $REGION --tasks 8 --task-timeout 3h \
  --args=-m,jobs.backfill,--start,2019-08-01,--end,2019-09-30,--night-only

Ingest tanpa retry karena siklus berikutnya 10 menit lagi dan job idempoten per timestamp. FIRMS tiap 30 menit karena latensi VIIRS NRT sekitar 3 jam; menarik lebih sering tidak menambah data.

14 · Urutan deploy

Dari project kosong sampai jadwal berjalan

  1. Project, billing, env.sh, aktifkan API, daftar Earth Engine.
  2. Service account dan peran, secret FIRMS dan Telegram.
  3. Bucket, Firestore. Unggah peat mask dan data mentah jendela backtest.
  4. Jalankan baseline untuk jendela backtest (lokal atau job).
  5. Deploy asapify-api, cek /api/v1/health, simpan chat_id grup Telegram.
  6. Deploy kedua job, jalankan ingest dengan --as-of di jendela backtest.
  7. Buat jadwal Scheduler.
  8. Deploy web, aktifkan Auth, set akun operator demo.
  9. Pasang monitoring dan budget alert.
