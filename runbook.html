00 · How to use

Before running any command

Conventions

  • Every command runs from the repo root asapify/, with the venv active (source .venv/bin/activate) and source infra/env.sh.
  • All times in code and arguments are UTC (suffix Z). Night = 13:00–21:00 UTC = 20:00–04:00 WIB.
  • <…> marks a value you must replace. There are no other placeholders.
  • Reference code (region, peat mask, Himawari, GK2A, NASA POWER, MAUT, agent, Telegram) is in Backend & API; gcloud commands are in Cloud setup.
  • ⚠️ = not verified yet. If the result differs from what is written, note it in the WORKLOG log and tell the owner of the next task.

Proof of done

  • Write in WORKLOG section 18: Done: <ID> — <summary> — <evidence>. Evidence = a file path, the output of the check command, or a link.
  • Code lands through a PR to main; the task's unit tests must pass in the PR.
  • Secrets (MAP_KEY, bot token) never go into the repo, chat or screenshots.

import glob, numpy as np
from satpy import Scene
from jobs.lib.region import AREA
def grid(reader, files, ch):
    s = Scene(reader=reader, filenames=files); s.load([ch], calibration="brightness_temperature")
    return s.resample(AREA, resampler="nearest", radius_of_influence=5000)[ch].values
h = grid("ahi_hsd", sorted(glob.glob("data/local/raw/himawari/*B07*")), "B07")
g = grid("ami_l1b", glob.glob("data/local/raw/gk2a/*sw038*"), "SW038")
for n, a in (("Himawari B07", h), ("GK2A SW038", g)):
    print(n, "NaN:", round(float(np.isnan(a).mean()), 4), "min/max K:", np.nanmin(a), np.nanmax(a))
m = ~np.isnan(h) & ~np.isnan(g)
print("correlation:", round(float(np.corrcoef(h[m], g[m])[0, 1]), 3))
EOF

import s3fs, datetime as dt
fs = s3fs.S3FileSystem(anon=True); now = dt.datetime.utcnow()
h = sorted(fs.ls(f"noaa-himawari9/AHI-L1b-FLDK/{now:%Y/%m/%d}"))[-1]

g = sorted(fs.ls(f"noaa-gk2a-pds/AMI/L1B/FD/{now:%Y%m/%d}"))[-1]
gf = sorted(x for x in fs.ls(g) if "sw038" in x)[-1]
gs = dt.datetime.strptime(gf[-15:-3], "%Y%m%d%H%M")
for n, s, f in (("himawari", hs, hf), ("gk2a", gs, gf)):
    lm = fs.info(f)["LastModified"].replace(tzinfo=None)
    print(f"{n},{s:%Y-%m-%dT%H:%MZ},{(lm - s).total_seconds()/60:.1f}")
EOF

The list of pixels every job processes, their neighbours, and the NASA POWER cells that cover them.

import pandas as pd, matplotlib.pyplot as plt, os

EOF

A2Role A
