Sebelum menjalankan perintah apa pun

Konvensi

  • Semua perintah dijalankan dari root repo asapify/, dengan venv aktif (source .venv/bin/activate) dan source infra/env.sh.
  • Semua waktu di kode dan argumen UTC (akhiran Z). Malam = 13.00–21.00 UTC = 20.00–04.00 WIB.
  • <…> berarti nilai yang harus diganti. Tidak ada placeholder lain.
  • Kode acuan (region, peat mask, Himawari, FIRMS, agen, Telegram) ada di Backend & API; perintah gcloud di Konfigurasi Cloud.
  • ⚠️ = belum diverifikasi. Bila hasilnya berbeda dari yang tertulis, catat di WORKLOG log dan beri tahu pemilik tugas berikutnya.

Bukti selesai

  • Tulis di WORKLOG bagian 18: Selesai: <ID> — <ringkas> — <bukti>. Bukti = path file, keluaran perintah cek, atau link.
  • Kode masuk lewat PR ke main; unit test di tugas harus lulus di PR.
  • Rahasia (MAP_KEY, token bot) tidak pernah masuk repo, chat, atau screenshot.

Project GCP, billing, budget, API

Satu project untuk semua layanan, dengan budget alert supaya biaya Gemini terkendali.

Prasyarat

  • gcloud CLI terpasang (atau pakai Cloud Shell)
  • Akun billing Google Cloud

Keluaran

  • Project $PROJECT_ID dengan billing aktif
  • Budget alert 50/90/100%
  • infra/env.sh di repo

Langkah

  1. Masuk dan buat project. Ganti <inisial>.
    gcloud auth login
export PROJECT_ID=asapify-<inisial>-2026
gcloud projects create $PROJECT_ID --name="ASAPify"
  2. Hubungkan billing. Salin ACCOUNT_ID dari perintah pertama.
    gcloud billing accounts list
gcloud billing projects link $PROJECT_ID --billing-account=<ACCOUNT_ID>
  3. Pasang budget alert (angka 50 USD 💡, sesuaikan).
    gcloud billing budgets create --billing-account=<ACCOUNT_ID> \
  --display-name=asapify-budget --budget-amount=50USD \
  --threshold-rule=percent=0.5 --threshold-rule=percent=0.9 --threshold-rule=percent=1.0
  4. Buat infra/env.sh persis seperti blok di bagian "Variabel" halaman ini, lalu muat.
    source infra/env.sh
  5. Aktifkan API.
    gcloud services enable run.googleapis.com cloudscheduler.googleapis.com \
  artifactregistry.googleapis.com cloudbuild.googleapis.com firestore.googleapis.com \
  storage.googleapis.com secretmanager.googleapis.com aiplatform.googleapis.com \
  earthengine.googleapis.com iamcredentials.googleapis.com firebase.googleapis.com
  6. Beri akses anggota tim (ulangi per email).
    gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member=user:<EMAIL> --role=roles/editor

Cek selesai

Billing aktif:

gcloud billing projects describe $PROJECT_ID --format='value(billingEnabled)'   # harus: True

Tujuh API utama aktif:

gcloud services list --enabled --format='value(config.name)' | \
  grep -cE 'run|cloudscheduler|firestore|secretmanager|aiplatform|earthengine|storage.googleapis'   # harus: ≥ 7

import s3fs

  2. Unduh B07 dan B14 segmen S05 dan S06 dari bucket yang ada, catat ukurannya.

import s3fs

  3. Baca ke grid Kalimantan dan cek cakupan segmen.

import glob, numpy as np

from jobs.lib.region import AREA
f = sorted(glob.glob("data/local/raw/himawari/*B07*"))
scn = Scene(reader="ahi_hsd", filenames=f); scn.load(["B07"])
a = scn.resample(AREA, resampler="nearest", radius_of_influence=5000)["B07"].values

import s3fs, datetime as dt
fs = s3fs.S3FileSystem(anon=True)
now = dt.datetime.utcnow()
day = f"noaa-himawari9/AHI-L1b-FLDK/{now:%Y/%m/%d}"
last = sorted(fs.ls(day))[-1]                    # folder HHMM terbaru
f = [x for x in fs.ls(last) if "B07" in x and "S0510" in x][0]
scan = dt.datetime.strptime(last[-15:], "%Y/%m/%d/%H%M")
lm = fs.info(f)["LastModified"].replace(tzinfo=None)
print(f"{scan:%Y-%m-%dT%H:%MZ},{(lm - scan).total_seconds()/60:.1f}")
EOF
